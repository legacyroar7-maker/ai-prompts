# Everyday AI Prompts

**Copy, paste, fill in the [brackets]. Works with ChatGPT, Claude, Gemini and other AI assistants.**

Most people get weak answers from AI because they ask short, vague questions. These prompts give the AI a role, your details, and the exact format you want back. That is the whole trick.

---

## The 4-part formula behind every prompt here

1. **Role:** who the AI should act as ("You are a careful budget coach").
2. **Context:** your real situation, numbers and limits.
3. **Task:** one clear job.
4. **Format:** how you want the answer (a table, 5 bullets, under 100 words).

Add this line to any prompt for better answers:
```
Before you answer, ask me up to 3 questions if anything important is missing.
```

## 1. Daily planning

**Plan my day**
```
You are a calm, practical day planner.
Here is my day: [list tasks, meetings, errands, with times if fixed].
I have energy for deep work in the [morning/afternoon]. I must stop by [time].
Make a time-blocked plan with short breaks. Put the hardest task in my best energy slot.
Mark anything that can move to tomorrow. Answer as a simple table: time | task | note.
```

**Turn a messy brain dump into a to-do list**
```
Here is everything on my mind, in no order: [paste].
Sort it into: Do today, This week, Later, Delegate or drop.
For each "Do today" item, write the very first 5-minute step.
```

**Weekly reset**
```
Act as my weekly review coach. Last week I did: [wins]. I did not finish: [list].
Next week I have: [fixed events]. My one big goal is: [goal].
Give me 3 priorities for next week, what to say no to, and one habit to try.
Keep it under 150 words.
```

**Beat procrastination**
```
I keep avoiding [task] because [reason, be honest].
Break it into steps so small that each takes under 10 minutes.
Then write a 2-sentence pep talk that is kind but firm.
```

## 2. Writing messages and emails

**Write a clear email**
```
Write an email to [person/role] about [topic].
Goal: I want them to [action] by [date].
Tone: [friendly / formal / firm but polite]. Keep it under [120] words.
Give me 2 subject line options.
```

**Reply to a difficult message**
```
Here is a message I received: [paste].
I feel [annoyed / confused / hurt]. I want to [keep the relationship / set a boundary / ask for a refund].
Write a calm reply that is clear and respectful. No blame, no long excuses.
Then give me a shorter version too.
```

**Fix my writing**
```
Improve this text: [paste].
Keep my meaning and my voice. Make it shorter, clearer and easy to read.
Then list the 3 biggest changes you made and why.
```

**Say no politely**
```
Someone asked me to [request]. I want to say no because [reason, optional].
Write 3 short ways to decline: warm, neutral, and very brief.
```

## 3. Money and shopping

**Monthly budget**
```
Act as a practical budget coach (not a financial adviser).
My monthly income after tax: [amount]. Fixed costs: [rent, bills, loans].
Other spending last month: [list or paste bank categories].
Build a simple budget table with categories, current spend, suggested spend.
Show 3 easy places to save without making life miserable.
```

**Should I buy this?**
```
I want to buy [item] for [price]. I will use it for [purpose], about [how often].
My budget for this is [amount]. Alternatives I am considering: [list].
Compare them in a table: price, cost per use, pros, cons.
Then ask me 2 questions that would change the decision.
```

**Compare two offers**
```
Compare these two [phone plans / insurance quotes / job offers]: [paste both].
Show the real total cost over [12] months, hidden fees, and what each is best for.
Finish with a one-line summary for each.
```

**Return or complaint letter**
```
I bought [item] from [shop] on [date] for [price]. Problem: [what went wrong].
I want [refund / replacement / repair].
Write a short, polite but firm message. Include the key facts and a clear request with a deadline.
```

## 4. Food and home

**Meals from what is in my fridge**
```
I have: [list ingredients]. Basics I always have: salt, oil, spices, rice, pasta.
I have [30] minutes and [1 pan / oven / no oven]. Cooking for [2] people.
Give me 3 meal ideas. For the best one, write a step-by-step recipe with times.
```

**Weekly meal plan and shopping list**
```
Plan dinners for [5] days for [number] people. Budget about [amount] in total.
Preferences: [vegetarian / no pork / high protein / kid friendly].
Reuse ingredients across meals to waste less food.
Give me the plan, then one shopping list grouped by shop section.
```

**Clean and organise faster**
```
My [kitchen / wardrobe / garage] is a mess. I have [1 hour] today.
Give me a step-by-step plan in 15-minute rounds. Tell me what to do with items I am unsure about.
```

**Fix something at home**
```
Problem: [describe, e.g. the sink drains slowly]. What I already tried: [list].
Tools I have: [list]. Explain the likely causes from most to least likely,
and safe steps I can try myself. Tell me clearly when I should call a professional.
```

## 5. Learning and work

**Learn anything fast**
```
Teach me [topic] like I am a smart beginner.
Start with the 20% that gives 80% of the results. Use one simple example.
Then give me 5 quiz questions. Wait for my answers before you show the solutions.
```

**Explain this document**
```
Here is a [contract / letter / report]: [paste].
Summarise it in 5 bullet points in plain words.
Then list anything I must do, any deadlines, and anything that looks unusual or risky.
```

**Prepare for an interview or meeting**
```
I have a [job interview / client meeting] for [role or purpose] at [company].
About me: [short background]. Ask me the 8 most likely questions one by one.
After each answer, give me feedback and a stronger version of my answer.
```

**Write a CV bullet that sells**
```
Here is what I did in my job: [describe plainly].
Rewrite it as 3 strong CV bullet points. Start each with an action verb.
Use numbers only if I gave them. Do not invent results.
```

## 6. Travel

**Plan a trip**
```
Plan a [3]-day trip to [city] for [who] in [month]. Budget about [amount] per day.
We like [food / museums / nature / nightlife] and dislike [crowds / long walks].
Give a day-by-day plan with morning, afternoon, evening. Group places that are close together.
Add one rainy-day backup.
```

**Packing list**
```
Make a packing list for [days] days in [place] in [month], for [activities].
I travel with [carry-on only / a suitcase]. Group the list by category and mark the items people forget.
```

## 7. Selling online

**Product listing that sells**
```
You are an expert online seller on [Vinted / eBay / Etsy / Shopify].
Item: [what it is, brand, size, colour, condition, flaws].
Write: 1) a title under [80] characters with the words buyers search for,
2) a short, honest description with bullet points, 3) 5 search tags.
Do not exaggerate. Mention flaws clearly.
```

**Price my item**
```
I want to sell [item, brand, condition]. Similar items sell for: [paste prices you found].
Suggest a fast-sale price, a fair price and a patient price, and explain each in one line.
```

**Answer a buyer**
```
A buyer wrote: [paste]. My policy: [shipping, returns, lowest price].
Write a friendly, short reply that answers the question and moves them to buy.
```

**Product page with SEO and AEO**
```
Write a product page for [product] for [who it is for].
Main keyword: [keyword]. Key facts: [size, material, use, care, delivery].
Give me: an SEO title under 60 characters, a meta description of 120 to 160 characters,
a description with short sentences and 4 bullet points, and 4 FAQs with direct answers.
Use the keyword naturally, no more than 3 times.
```

## 8. Running a small business

**Customer reply templates**
```
I run a [type of business]. Write 6 short reply templates for:
late delivery, refund request, discount request, a happy review, an angry review, and "is this in stock?".
Tone: warm and professional. Use [brackets] for the parts I fill in.
```

**Social media week**
```
Plan 7 posts for [business] on [Instagram / TikTok / Facebook].
My buyers are [who]. This week I want to promote [product or offer].
For each day: post idea, caption under 60 words, and 5 hashtags. Mix tips, behind the scenes and product posts.
```

**Find the problem in my numbers**
```
Here are my numbers for the last [3] months: [sales, costs, ad spend, returns].
Show me in a table what changed month to month. Point out the 3 biggest problems and one simple action for each.
Do not guess numbers I did not give you.
```

## 9. Make any AI answer better

**Add these lines when an answer is weak**
```
Be specific. Use my details, not general advice.
Give me the answer in [a table / 5 bullets / steps].
If you are not sure about something, say so instead of guessing.
Now make it 50% shorter.
Give me 3 different versions so I can choose.
```

**Ask the AI to check itself**
```
Review your last answer. What is missing, wrong or too general?
Fix it and show me only the improved version.
```

**Save your own "about me"**
Many AI tools let you save custom instructions. Paste something like:
```
I live in [country]. I work as [job]. I prefer short, clear answers with steps.
Use simple English. Ask me questions when my request is unclear.
```

---

### A few honest rules
- AI can be wrong. Check important facts, numbers and anything about health, law or money with a real professional.
- Do not paste passwords, card numbers or private data of other people.
- The better your details, the better the answer.
